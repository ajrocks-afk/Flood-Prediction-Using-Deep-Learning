# Flood Prediction Using Deep Learning Models

### Deep Learning Based Flood Prediction System with Model Comparison and Hyperparameter Tuning

* **Aim of the project** :
 The aim of this project is to build a flood prediction system using different deep learning models and compare their performance. The project focuses on preprocessing the dataset, performing EDA, training multiple models, tuning them, and analyzing which model performs best for flood prediction.

## What I worked on in this project 🚀

In this project, I implemented and compared multiple deep learning models for flood prediction.

The work includes:

* Data preprocessing and feature scaling
* Exploratory Data Analysis (EDA)
* Checking missing values, duplicate values, and negative values
* Correlation heatmap and data visualization
* Implementation of:

  * ANN
  * 1D-CNN
  * LSTM
  * GRU
  * CNN-LSTM
  
* Hyperparameter tuning for all models
* Performance comparison using MAE, RMSE, and R² score
* Visualization graphs for model comparison
* Added proper explanations, conclusions, and documentation in the notebook and README

The main goal was to compare how different deep learning architectures perform on flood prediction data and analyze the impact of tuning on model performance.
